# TopScroll

Аддон для PulseSync, который добавляет невидимую кликабельную зону по левому краю экрана для быстрой прокрутки страницы

## Как использовать

- **Левый клик** по левому краю — прокрутить страницу наверх
- **Левый клик повторно** (когда уже наверху) — вернуться к предыдущей позиции
- **Правый клик** по левому краю — прокрутить страницу вниз
